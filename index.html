    Settings

    Layout

    Control bar position
    Table and details
    Back and Forward buttons The ← and → buttons beside the logo, which go back and forward through the commands, scripts, terms and notes you've viewed.
    Scratch pad The note area under the Spell Book's detail pane. Its text is kept while it's hidden.
    Quick filters Applies to the Command, Script and Term filter buttons. Several at once shows entries matching any selected filter, such as PowerShell + CMD.
    Options in the detail pane Whether the Options section starts open. You can still open or close it for any command.
    Table pane location "In the control bar" puts the table pane under the sections, with a draggable divider, and the detail pane fills the rest. It takes effect when the control bar is on the left or right.

    Theme Colors

    Individual Category Colors

    Set a distinct color for each command platform, script language, or term category. These colors apply to both badges and filter buttons.

    Save or load these colors with Import / Export in the top bar.

    Code Blocks

    # Find a process on a remote machine
$name = Read-Host 'Process name'
Get-CimInstance Win32_Process -Filter "Name = '$name'" | Select-Object -First 1

    Applies to command templates, generated commands, examples, scripts and the README.

    Syntax Colors

    Fine-tune the colors of the chosen code theme. Choosing a different theme, or switching light / dark mode, resets these.

    Fonts

    Pick a font for each part of the page. Only a short list of common fonts is offered, and only the typeface changes, so buttons, layout and sizes keep working. Code blocks and the scratch pad use fixed-width fonts only, so columns stay lined up.

    Linked Data File

    Link a JSON file to keep all your data and settings (commands, scripts, terms, colors and layout) in one place. It loads automatically when Spell Book opens. Works in Chrome and Edge.

    Any browser, including when Spell Book is opened as a local file, can use these instead. Download Backup downloads spellbook-data.json. On HTTP(S), a snapshot placed in the data folder can seed a fresh browser. For local file:// use, select Restore From File instead. Restore From File loads a JSON backup right now (legacy JavaScript backups are also accepted).

    Local Data

    These controls affect only data saved by this browser. They do not delete or modify the JSON files in data/.

    Clear Local Commands reloads the bundled JSON files on the next HTTP(S) load if no local records remain. On file://, use Restore From File. Reset All clears locally saved records and settings.

    Insert Command

    New Command

    Type a tag and press Enter or a comma. Existing tags are suggested as you type, and every tag becomes available in the Tag filter.
    Use <name> for required placeholders and [name] for optional placeholders. Both become editable fields; optional placeholders are omitted from the generated command until populated. All placeholders must NOT contain whitespace (e.g. spaces, tabs, etc.), e.g. use "<variable_name>", NOT "<variable name>" For dropdown lists, use <option1 | option2 | option3> syntax
    Give each variable a type, a description and any extra information (required, position, default value…). Insert puts it into the command template at the cursor, as <name> or the optional [name]. Variables you leave out here are still picked up from the template.
